# 🧠 Architecture

The project follows a clean and modular structure to improve maintainability, readability, and scalability.

| File | Purpose |
|------|----------|
| `index.php` | Homepage and main book display section |
| `login.php` | Handles user authentication and login functionality |
| `signup.php` | Manages user registration and account creation |
| `books.php` | Displays book listings and browsing functionality |
| `admin.php` | Admin dashboard for managing books and records |
| `db_connect.php` | Handles MySQL database connectivity |

# ▶️ How to Run

Follow these steps to run the project locally on your system.

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/influential-books-web-platform.git
```

---

## 2️⃣ Move Project to XAMPP htdocs Folder

Copy the project folder into:

```bash
C:/xampp/htdocs/
```

---

## 3️⃣ Start Apache and MySQL

Open the **XAMPP Control Panel** and start the following services:

- Apache
- MySQL

---

## 4️⃣ Create Database

Create a MySQL database named:

```sql
influential_books
```

Then import the required SQL tables into the database.

---

## 5️⃣ Run the Project

Open your browser and visit:

```bash
http://localhost/influential-books-web-platform/
```
