## 🚀 Features

- 👤 User Signup & Login Authentication
- 📚 Browse Influential Books
- 🔍 View Book Details
- 🛠 Admin Panel for Book Management
- 💾 MySQL Database Integration
- 🎨 Clean and Responsive UI
- 🔐 Session Management using PHP

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP / Localhost
